
# 📘 Atividade: Jogo da Forca em Python

## 🎯 Objetivo

Crie um jogo da Forca no terminal para praticar manipulação de strings, listas, condicionais, loops e entrada de dados. O jogador deverá adivinhar uma palavra escolhida aleatoriamente antes de esgotar as tentativas incorretas.

## 📝 Tarefas

### 🛠️ Preparar a palavra secreta

#### Descrição

Use a lista de palavras predefinida no código inicial para escolher a palavra da partida e preparar as variáveis que serão usadas pelo jogo.

#### Requisitos

O programa concluído deve:

- Escolher uma palavra aleatoriamente da lista.
- Registrar as letras tentadas e inicializar a contagem de tentativas incorretas e o limite de tentativas.
- Mostrar a palavra oculta usando sublinhados e revelar as letras que o jogador acertar (por exemplo: `_ _ a _`).

### 🛠️ Executar a partida

#### Descrição

Implemente as rodadas de palpites e atualize o estado do jogo até que o jogador vença ou esgote as tentativas.

#### Requisitos

O programa concluído deve:

- Receber palpites de letras do jogador.
- Atualizar e exibir o progresso da palavra após cada palpite.
- Contar os palpites incorretos restantes.
- Encerrar quando todas as letras da palavra forem descobertas ou o limite de tentativas incorretas for atingido.
- Exibir uma mensagem indicando vitória ou derrota.
